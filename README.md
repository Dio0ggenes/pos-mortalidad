# Posmortal (Forge 1.20.1)

Posesión de cuerpos y Tótem de la Posmortalidad.

## Compilar
- En GitHub: sube el proyecto y ve a Actions > Build mod. Descarga el .jar del artefacto `posmortal-jar`.
- En local: JDK 17 y `gradle build` (Gradle 8.1.1). El .jar queda en `build/libs`.

## Uso
- Receta: 3 tótems de la inmortalidad (fila de arriba) + 3 bloques de diamante (fila de abajo).
- Tótem a un jugador (clic derecho): al morir reaparece como fantasma.
- Fantasma: clic derecho sobre un mob para poseerlo. `/posmortal salir` para salir.
- Tótem a un mob: al morir queda como cuerpo rojo reutilizable (3 salidas, jefes 1).
- `/posmortal fantasma` (op) para probar.
